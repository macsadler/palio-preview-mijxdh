Palio di Siena - Monturati luglio 1885



- I MONTURATI PER IL PALIO DI LUGLIO 1885 -



La Comparsa di questo Palio era formata soltanto dalle 10 Contrade partecipanti alla corsa ed era composta dal Duce (o Capitano come appare nei fogli prestampati del Comune), un solo Alfiere, il Tamburino, il Barberesco e quattro Paggi.



BRUCO

Duce - Vannini Santi, via Vallerozzi 51
Alfiere - Magnielli Sabbatino, via degli Orti 11
Barberesco - Lorenzetti Paolo, via del Comune 18
Tamburo - Magnielli Francesco, del Comune 24
Paggio - Vanni Cesare, via Baroncelli 4
Paggio - Vannini Fiore, via Vallerozzi 51
Paggio - Crezzini Augusto, via del Comune 28
Paggio - Giannini Dante, via del Comune 25

CHIOCCIOLA

Duce - Franci Giuseppe, via Duprè
Alfiere - Carli Celso, via S.Marco 43
Barberesco - Fuochi Alduino, via S.Marco 25
Tamburo - Petrolini, via S.Marco
Paggio - Umicini Oreste
Paggio - Lotti Ugo, via S.Marco 29
Paggio - Berni Leopoldo, fuori la Porta S.Marco
Paggio - Fuochi Casimirro, via S.Marco 25

DRAGO

Duce - Beccherini Ferdinando, via Duprè
Alfiere - Belli Giuseppe, via del Paradiso
Barberesco - Donati Edoardo, via delle Belle Arti*
Tamburo - Marri Mariano, di Poggibonsi
Paggio - Ghini Ettore, via Camullia
Paggio - Saccardi Edoardo, via Camullia
Paggio - Cimballi Filippo, via Camullia
Paggio - Righi Massimiliano, via Salicotto

GIRAFFA

Duce - Santini Angiolo, via S.Martino 51
Alfiere - Silei G.Battista, via Benincasa
Barberesco - Stacchini Giacomo, via Baroncelli 19
Tamburo - Potenti Giuseppe, via Camullia 26
Paggio - Pruneti Ferdinando, via Baroncelli 23
Paggio - Fabbri Ernesto, via del Giglio 22
Paggio - Pieraccini Umberto, via del Fosso 4
Paggio - Del Bigio Luigi, via delle Vergini 14

LUPA

Duce - Melani Angiolo, via delle Scalelle
Alfiere - Muzzi Natale, via Vallerozzi
Barberesco - Gori Luigi, via Vallerozzi
Tamburo - Baroni, di Sovicille
Paggio - Sestigiani Giuseppe, via Vallerozzi
Paggio - Biotti Celso, via Vallerozzi
Paggio - Pascucci Celso, via Vallerozzi
Paggio - Buti Virgilio, via Vallerozzi

NICCHIO

Duce - Lorenzetti Baldassarre, via S.Vigilio
Alfiere - Pozzoli Sabatino, via dell'Oliviera 10
Barberesco - Marzocchi Carlo, via Fieranuova 57
Tamburo - Ricci Cesare, via S.Marco 16
Paggio - Neri Alfredo, via del Comune 42
Paggio - Pacciani Torquato, via Fiera Nuova
Paggio - Masini Tito, via Ricasoli 24
Paggio - Cantagalli Cesere, via dei Pispini 42

OCA

Duce - Boninsegni Antonio, via dei Pittori 9
Alfiere - Pacini Gaetano, via Benincasa 24
Barberesco - Tancredi Pietro, via dei Pittori 10
Tamburo - Marzi Eugenio, via Benincasa 23
Paggio - Bozzini Ferruccio, via Benincasa 36
Paggio - Tancredi Dante, via Fontebranda 4
Paggio - Testi Eliseo, via della Galluzza 17
Paggio - Cortecci Ottavio, via del Tiratoio 7

PANTERA

Duce - Lusini Bernardino, via dei Maestri (attuale via Tito Sarrocchi)
Alfiere - Forni Sabatino, via Duprè
Barberesco - Bianciardi Arturo, via Franciosa
Tamburo - Meini Sestiglio, via dei Pispini
Paggio - Ricci Casimirro, via Duprè
Paggio - Forni Gherardo, via Salicotto
Paggio - Senatori Raffaello, via dell'Uliviera
Paggio - Casini Carlo, via del Nuovo Asilo*
* Secondo lo Stradario Mazzi del 1871 era tutta la strada che scendeva dal Pian de' Mantellini fino a Porta Laterina e che proseguiva lungo le mura fino a Porta S.Marco; oggi corrisponde al tratto che unisce Porta Laterina a Porta S.Marco e che in precedenza era detta Strada del Laterino.
