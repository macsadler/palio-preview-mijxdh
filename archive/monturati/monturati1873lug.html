Palio di Siena - Monturati luglio 1873



- I MONTURATI PER IL PALIO DI LUGLIO 1873 -


Non sappiamo con precisione come fosse composta la Comparsa di questo Palio. Nei fogli prestampati, che dovevano compilare le Contrade, il Duce veniva chiamato Capitano e il Tenente colui che oggi sarebbe il Paggio Maggiore. Partecipavano al corteo solo i figuranti delle Contrade che correvano.



BRUCO

Duce - Bruni Antonio, via Castelvecchio 24
Tenente - Pucci Tommaso, via della Diana 9

CIVETTA

Duce - Capannoli Giuseppe, via Benincasa 24
Tenente - Morandi Ippolito, via Benincasa 24

DRAGO

Duce - Falini Cesare, via delle Belle Arti
Tenente - Partini Giuseppe, via Duprè

GIRAFFA

Duce - Petrolini Giuseppe, via dei Rossi
Tenente - Partini Bernardino, via delle Vergini

ISTRICE

Duce - Lotti Giuseppe, via Camollia 61
Tenente - Cappelli Giuseppe, via Camollia 64

LEOCORNO

Duce - Lorenzini Giovanni, via degli Archi 4
Tenente - n.r.

LUPA

Duce - Minghi Emilio, via di Vallerozzi 39
Tenente - Baldini Carlo, via di Vallerozzi 29

NICCHIO

Duce - Pozzuoli Giovanni, via S.Francesco 44
Tenente - Pozzuoli Sabatino, via S.Chiara 1

TORRE

Duce - Mariani Giuseppe, via Salicotto 41
Tenente - Campanini Socrate, via Salicotto 41

VALDIMONTONE

Duce - Turchi Bernardino, via di Salicotto 126
Tenente - n.r.
